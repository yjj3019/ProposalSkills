# 3장 리드문 골격 (합성)

## 장표 3 — 제안 개요
**리드문:** 가상공공기관 A는 업무시스템의 클라우드 랜딩존과 12개월 MSP를
한 계약으로 확보해, 감사 대응과 운영 가시성을 동시에 얻는다.

- REQ-001, REQ-002 | WT-1, WT-2
- 시각: 범위(랜딩존→이관→MSP) 한 장 도식

## 장표 4 — 공유책임 RACI
**리드문:** CSP·MSP·기관의 승인(A) 주체를 업무별로 한곳에 고정해
장애·변경·키 관리 책임을 혼선 없이 운영한다.

- REQ-002, REQ-003 | WT-2
- 시각: RACI 표 (공동 표기 금지)

## 장표 5 — SLA·FinOps
**리드문:** 응답 15분·복구 4시간을 제외 사유와 함께 약속하고,
월간 운영·분기 비용 최적화 보고로 측정 가능하게 관리한다.

- REQ-004, REQ-005 | WT-3
- 시각: SLA 표 + 보고 캘린더
