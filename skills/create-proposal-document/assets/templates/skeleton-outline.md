# 유형별 골격 목차 (템플릿)

RFP가 목차를 지정하면 **지정 목차가 우선**한다. 아래는 내부 기본 골격이다.

## 유형 A — 구축

1. 표지·목차·요약(5질문)
2. 이해·요구(현황, 과제, 평가 포인트)
3. 솔루션 아키텍처·구성
4. 수행 방안(일정·Wave·위험·품질)
5. 사업관리·보안·기술이전
6. 인력·조직·실적·차별화
7. 조견표·별첨 목록

## 유형 B — 유지보수·기술지원·MSP

1. 표지·목차·요약
2. 서비스 범위·책임분담(RACI)·Exit
3. 운영 절차·예방점검·이원 SLA
4. 장애·변경·보고
5. 인력(상주/온콜)·백업
6. 실적·인증·조견표

## 유형 C — 기술답변서

1. 표지·응답 요령
2. 항목별 답변(요구 ID 순서)
3. 준수 수준·예외·증빙 인덱스
4. 보충 기술 자료(필요 시)

상세 장표 문법: `references/proposal-structure.md`.
