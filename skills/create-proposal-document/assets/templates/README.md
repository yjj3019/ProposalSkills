# 제안 작성 템플릿

이 폴더는 **민감 정보 없는** 작성 골격이다. 실제 수주 PPTX는
`../approved-examples/`(조직 로컬)에만 두고 배포본에는 넣지 않는다.

| 파일 | 용도 | 다음 단계 |
|---|---|---|
| `compliance-matrix.md` | 요구사항 조견표 뼈대 | `scripts/mapping_check.py` |
| `page-message-map.md` | 장표별 리드문(거버닝 메시지) | 목차 확정 후 본문 작성 |
| `skeleton-outline.md` | 유형 A/B/C 목차 초안 | RFP 지정 목차가 있으면 교체 |

합성 예제(가상 공공 클라우드): `../examples/synthetic-public-cloud/`.
